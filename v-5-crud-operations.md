# HTTP Methods in FastAPI

In this video, I learned about HTTP methods and how they are used to perform different operations on a server.

## 1. GET Method

GET is used to read or retrieve data from a server.

For example, if I want to see all products available on a server, I can use the GET method to get the product data.

**Use:** To fetch existing data without changing it.

## 2. POST Method

POST is used to send data to a server and create a new resource.

For example, if I want to add a new product to the product list, I can use the POST method to send the product details to the server.

**Use:** To create new data.

## 3. PUT Method

PUT is used to update or replace an existing resource on a server.

For example, if I want to change the price of an existing product, I can use the PUT method to send the updated product details.

**Use:** To update or replace existing data.

## 4. DELETE Method

DELETE is used to remove an existing resource from a server.

For example, if I want to remove a product from the product list, I can use the DELETE method to request its removal.

**Use:** To delete existing data.

## What I Learned

* GET is used to read data.
* POST is used to create new data.
* PUT is used to update or replace existing data.
* DELETE is used to remove data.
