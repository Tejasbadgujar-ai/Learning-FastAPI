# Video 1: FastAPI Introduction

## 1. What is FastAPI?

* FastAPI is a modern Python web framework.
* It is used to build APIs and backend applications.
* It helps the frontend communicate with the backend.

## 2. Why Use FastAPI?

* It provides good performance.
* It is easy to learn and use.
* It supports asynchronous programming.
* It supports automatic API documentation.
* It uses Pydantic for data validation.

## 3. What Will I Learn in This Course?

* CRUD operations: GET, POST, PUT, and DELETE.
* Database connectivity with PostgreSQL and SQL.
* User registration and login.
* Authentication and token generation.
* Sending emails to users.
* Running background tasks.
