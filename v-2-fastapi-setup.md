## FastAPI Setup

### What I Learned

* I learned how to create a Python virtual environment using `python -m venv env`.

* I learned how to activate the virtual environment in PowerShell.

* I learned that a virtual environment helps keep project packages separate.

* I learned how to create a `main.py` file and run a simple Python program using the `print()` function.

* I learned how to install FastAPI using pip.

* I learned that `pip` is a tool used to install Python packages.

* I learned that the virtual environment should not be uploaded to GitHub. It can be excluded using a `.gitignore` file.

### Commands Used

Create a virtual environment:

`python -m venv env`

Activate the environment in PowerShell:

`.\env\Scripts\Activate.ps1`

Install FastAPI:

`python -m pip install fastapi`

Check the installed FastAPI package:

`python -m pip show fastapi`

Run the Python file:

`python main.py`

### Summary

In this video, I learned the basics of setting up a Python environment, creating a Python file, running a simple program, and installing FastAPI using pip.
